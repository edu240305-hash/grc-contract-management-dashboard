## 📌 Overview
This project demonstrates a structured approach to IT Governance, Vendor Management, and Contract Control using KPIs and analytics.

The solution simulates a real corporate environment where multiple vendors, contracts, and SLAs must be monitored to ensure:

- Financial control  
- Compliance (SOX / ITGC)  
- Risk mitigation  
- Operational performance

## 🎯 Objectives
- Provide executive visibility of contracts and vendors  
- Monitor SLA performance and risk exposure  
- Control budget vs actual consumption  
- Support decision-making through analytics  

---

## 📊 Key KPIs
- Contract Consumption (%)  
- Budget Deviation (%)  
- SLA Compliance (%)  
- Vendor Risk Score  
- Contracts Near Expiration  
- MTTR / MTTA  

---

## 🧠 Governance Controls Implemented
- Contract lifecycle control (start/end/renewal alerts)  
- Financial tracking (contracted vs invoiced)  
- Documentation compliance checklist  
- SLA monitoring and performance tracking  
- Vendor risk classification model  

---

## 🛠 Tools & Technologies
- Excel (data modeling)  
- Power BI (dashboard)  
- Governance frameworks: COBIT, ITIL, SOX

## 🚀 Business Impact
- Reduction of financial leakage  
- Improved contract visibility  
- Better vendor performance management
